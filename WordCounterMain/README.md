# 🧮 Word Counter :
Word Counter is a simple Django web application that counts the number of words entered by the user.  
Through this project one can understand URL routing, templates & forms.

## 🚀 Features :

- Counts words from user input
- Simple and clean UI
- Uses Django template engine
- Beginner-friendly project structure
- Fast and lightweight

## 🧠 Tech Stack :

- Python
- Django
- HTML
- CSS
- SQLite3
