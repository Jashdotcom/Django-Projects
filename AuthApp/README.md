# 🔐 AuthApp :
AuthApp is a simple authentication web application built using **Django**.  
It allows users to log in and log out securely and shows a proper **“Invalid credentials”** message when incorrect login details are entered.

## 🚀 Features :

- ✅ User login using Django’s built-in authentication system  
- 🔐 Secure logout with POST + CSRF protection  
- ❌ Displays **Invalid credentials** for wrong username or password  
- 🔁 Redirects to home page after login and logout  
- 🎨 Clean UI using **Bootstrap 4**  
- 🧼 Simple and beginner-friendly project structure  

## 🧠 Tech Stack :

- **Backend:** Python, Django  
- **Frontend:** HTML, Bootstrap 4  
- **Database:** SQLite3  
- **Authentication:** Django default auth system
